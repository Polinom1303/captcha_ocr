Решение финального задания по курсу **Deep Learning Basic**. В рамках проекта реализована глубокая сверточно-рекуррентная нейронная сеть (CRNN) для распознавания текстовых символов на сильно зашумленных изображениях капчи.

## Архитектура модели (AdvancedCRNN)
Модель объединяет три мощных концепта для задач распознавания текста (OCR):
1. **Feature Extractor (CNN):** Глубокая VGG-style сеть (4 сверточных блока с `BatchNorm2d`, `ReLU` и `MaxPool2d`), сжимающая изображение по высоте и извлекающая пространственные признаки.
2. **Sequence Predictor (RNN):** Двунаправленная 2-слойная **Bi-LSTM** (`hidden_size=256`), анализирующая контекст символов как слева направо, так и справа налево.
3. **Linear Predictor (FC):** Полносвязный классификатор, возвращающий логиты вероятностей для каждого временного шага.

## Результаты обучения и аппаратный анализ (CPU vs GPU)
Обучение проводилось на протяжении **20 эпох** с использованием оптимизатора `Adam` (lr=0.005) и адаптивного планировщика шага `ReduceLROnPlateau`. При фиксации генератора случайных чисел (`torch.manual_seed(42)`), зафиксировано расхождение финальных метрик на разном типе вычислительных устройств:

| Вычислительное устройство | Validation CER (Посимвольная ошибка) | Validation Accuracy (Full Match Acc) |
| :--- | :---: | :---: |
| **GPU (NVIDIA T4 CUDA)** | **3.18%** | **88.32%** |
| **CPU (Intel Core / Local)** | **7.10%** | **76.64%** |

*Анализ расхождения:* Различие результатов обусловлено **аппаратным недетерминизмом параллельных вычислений**. Низкоуровневые библиотеки cuDNN (GPU) и MKL (CPU) по-разному оптимизируют последовательность математических операций над матрицами. Из-за микроокруглений чисел типа `float32` порядок сложения градиентов меняется, что в чувствительных рекуррентных слоях (LSTM) накапливается вдоль всей длины капчи. Это приводит к разным траекториям спуска оптимизатора `Adam`. На GPU сходимость модели за 20 эпох оказалась более глубокой и эффективной.

## Анализ ошибок на CPU

В ходе валидации модели на изолированной тестовой выборке (214 примеров) было зафиксировано **25 изображений с частичными ошибками**. 

### 1. Распределение ошибок по позициям (1-5 символы):
* **Позиция 1:** 4 ошиб(ок) (11.8%)
* **Позиция 2:** 3 ошиб(ок) (8.8%)
* **Позиция 3:** **11 ошиб(ок) (32.4%)**
* **Позиция 4:** **12 ошиб(ок) (35.3%)**
* **Позиция 5:** 4 ошиб(ок) (11.8%)

*Вывод:* Наблюдается классический краевой эффект рекуррентных сетей. На краях слов (1 и 5 символы) модели проще локализовать знаки, тогда как в центре капчи (3 и 4 позиции) плотность наложения букв и шума максимальна, что генерирует **67.7% всех ошибок** проекта.

### 2. Матрица путаницы (Топ-3 пары частых замещений):
* Истинный символ `'m'` -> ошибочно предсказан как `'n'`: **13 раз(а)**
* Истинный символ `'n'` -> ошибочно предсказан как `'m'`: **5 раз(а)**
* Истинный символ `'y'` -> ошибочно предсказан как `'g'`: **3 раз(а)**

*Вывод:* Основная сложность модели заключается в дифференциации символов со схожей геометрической структурой (`m` и `n`) при их размытии или склеивании шумом капчи.

## 🚀 Запуск проекта
1. Установите зависимости: `pip install torch torchvision matplotlib tqdm Pillow`
2. Поместите изображения капч в директорию `data/samples/`. Имя файла должно являться его текстовой меткой (например, `2b827.png`).
3. Запустите консольное обучение:
   ```bash
   python utils/train.py
   ```
4. Для проведения исследований, построения графиков Loss/CER и интерактивного разбора ошибок откройте файл `notebook.ipynb`.
